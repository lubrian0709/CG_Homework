1. Line (直線) (自力完成)
我使用中點直線演算法（Midpoint Line Algorithm）的概念實作直線繪製。首先，計算直線兩端點的水平與垂直位移，並利用位移量計算斜率及決策參數 d，以判斷下一個應該繪製的像素位置。接著，根據兩端點的相對位置，將直線分成四種方向進行處理，並依照斜率的大小，進一步區分直線較陡或較平緩的情況。演算法會根據決策參數的正負，選擇沿水平或垂直方向前進，或同時改變水平與垂直座標，並更新決策參數，以決定下一個像素的位置。最後，透過 drawPoint(x, y, color(0, 0, 0)) 將每個計算出的像素繪製成黑色，直到抵達線段的終點，完成直線的光柵化。此方法能夠以逐像素的方式近似理想直線，而不需要使用內建的 line() 函式。

2. Circle（圓）(透過ChatGPT協助完成)
我使用 Midpoint Circle Algorithm（中點圓演算法）繪製圓形。首先設定圓心與半徑，接著利用決策參數判斷下一個像素的位置，並根據八向對稱性，將計算出的像素座標映射至圓的其他對稱區域，以減少重複運算。最後，透過 drawPoint() 將像素繪製到畫面上。

3. Ellipse（橢圓）(透過ChatGPT協助完成)
我使用 Midpoint Ellipse Algorithm（中點橢圓演算法）繪製橢圓。由於橢圓在不同區域的斜率變化不同，因此將繪製過程分為兩個區域，分別根據決策參數判斷下一個像素的位置，並利用四向對稱性繪製其他部分。此方法能夠在不使用內建橢圓繪圖函式的情況下，完成橢圓的光柵化。

4. Curve（三次 Bézier 曲線）(透過ChatGPT協助完成)
我使用 De Casteljau 中點細分法（Midpoint Subdivision）繪製三次 Bézier 曲線。首先，利用四個控制點計算相鄰點的中點，再繼續計算新線段的中點，將原始曲線分割成左右兩段子曲線。接著，以遞迴方式重複細分，直到曲線足夠平坦或達到最大遞迴深度。最後，使用逐像素線段演算法連接各段的端點，並透過 drawPoint() 完成繪製。

5. Eraser（橡皮擦）(透過ChatGPT協助完成)
首先，利用兩個輸入點計算矩形的水平與垂直邊界，並使用 Math.min() 與 Math.max() 確保兩點順序不影響結果。接著，使用兩層迴圈逐一遍歷矩形範圍內的像素，將每個像素的顏色改為作業指定的背景色 color(250)，藉此清除矩形範圍內原有的圖形。
